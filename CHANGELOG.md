# Changelog

All notable changes to Serica will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.2.0] — 2026-09-01

### Added

- Initial public release: single-engine DuckDuckGo search with HTTP and MCP
  gateways, URL extraction pipeline, Redis caching, per-client rate limiting,
  outbound proxy support, and SSRF hardening.
